# React Timer

Timer de ciclos de trabalho. Eu informo a tarefa e quantos minutos quero focar, o contador roda e, quando termina, o ciclo vai para o histórico. Também dá para interromper um ciclo no meio.

## Tecnologias

- React 18 e TypeScript
- Vite
- styled-components
- React Router
- React Hook Form e Zod
- Immer e date-fns

## Como instalar e rodar

```bash
npm install
npm run dev
```

Outros comandos: `npm run build` gera a versão de produção e `npm run lint` roda o ESLint.
